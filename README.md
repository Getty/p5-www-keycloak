# WWW-Keycloak

Perl client for [Keycloak](https://www.keycloak.org/) identity management: OIDC plus the
Admin REST API, modelled on [WWW::Zitadel](https://metacpan.org/pod/WWW::Zitadel).

**Status: skeleton.** Nothing is implemented yet.

Async twin: `Net::Async::Keycloak`.
